# Mực Mây Studio

Theme WordPress thương mại điện tử dành cho mucmayyy.id.vn. Phát triển riêng từ phiên bản 2.1, tích hợp WooCommerce.

**Trạng thái:** mã nguồn đang được đưa lên GitHub và cập nhật lên bản 2.2 có quản trị nội dung trong WordPress. Website iNET chưa được tự động cập nhật.

Không lưu mật khẩu WordPress, FTP/SFTP hoặc thông tin thanh toán trong Git. Chi tiết cách dùng và triển khai được bổ sung trong pull request.
